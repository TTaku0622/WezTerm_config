WezTerm チートシート

LEADER は Ctrl+q。押して離してから、2 秒以内に次のキーを押す。日本語入力は英数にしておく（かなのままだと効かない）。

サイドバーClaude Code の稼働状況

Cmd+E入力先を作業画面 ⇔ サイドバーで切り替え
LEADER→bサイドバーを出す／消す（2 回押すと作り直し）
境界線をドラッグ幅を変える（全タブ・次回起動に引き継ぐ）

色: 🟡 作業中　🟢 完了・入力待ち　🔴 許可や回答の待ち

サイドバーの中でCmd+E で入ったあと／マウス

1〜9・クリックAGENTS のそのエージェントのタブへ移動
j k / ↓ ↑ / ホイールHISTORY の選択を動かす
Enter・クリックHISTORY のセッションを新しいタブで再開
p・右クリックHISTORY のピン留め／解除

タブ

Cmd+T新しいタブ（サイドバー付き）
Cmd+Wタブを閉じる（確認あり）
Cmd+1〜8その番号のタブへ
Cmd+9最後のタブへ
Ctrl+Tab次のタブ
Ctrl+Shift+Tab前のタブ
Cmd+Shift+← / →タブを左／右へ並べ替え
LEADER→{ / }同上（前からのキー）

ペイン（画面分割）

LEADER→r右に分割
LEADER→d下に分割
LEADER→xペインを閉じる（確認あり）
LEADER→z今のペインだけ大きく表示／戻す
LEADER→hjkl左・下・上・右のペインへ移動
LEADER→a→hjklペイン移動（1 秒以内に方向キー）
Ctrl+Shift+[ペインを選ぶ（文字が出るので押して移動）

サイドバーにいるときも、分割・拡大は作業画面のほうに効く。サイドバーは LEADER → x では閉じない。

hjkl境界線を左・下・上・右へ 1 マス動かす

表示・その他

標準のキー割り当ては切ってあるので、ここに無いキー（Cmd+F の検索など）は効かない。迷ったらコマンドパレットで探す。
